A tiny Node program that writes one deadpan one-star review of sleep — an everyday essential nobody can opt out of — to the output directory as `entry.txt`. The review is a single line of at most 160 characters, filed in earnest against a thing that cannot be fixed.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
